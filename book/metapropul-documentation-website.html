Chapter 1 metapropul documentation website

This folder contains the source files for the metapropul bookdown site.

1.2 Building the site

1.2.1 Prerequisites

install.packages(c("bookdown", "metapropul"))  # metapropul from GitHub
# remotes::install_github("drrubesh/metapropul")

1.2.2 Build HTML

bookdown::render_book("index.Rmd", "bookdown::gitbook")

Or using the build script:

Rscript build.R

The rendered site appears in docs/. Open docs/index.html locally or deploy to GitHub Pages.

1.2.3 Build PDF

bookdown::render_book("index.Rmd", "bookdown::pdf_book")

1.3 Deploying to GitHub Pages

  1. Push the docs/ folder to your repository
  2. Go to Settings → Pages in your GitHub repository
  3. Set source to main branch / docs folder
  4. Your site will be live at https://drrubesh.github.io/metapropul/

1.4 Code chunks

All code chunks have eval = FALSE by default (_common.R). Set eval = TRUE in _common.R when building with the package installed and you want live output.
