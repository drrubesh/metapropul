# Example dataset: Olkin95

This dataset contains event counts from a set of studies comparing
treatment and control groups.

## Usage

``` r
data(Olkin95)
```

## Format

A data frame with 70 rows and 6 variables:

- author:

  Author name

- year:

  Year of publication

- event.e:

  Number of events in the experimental group

- n.e:

  Total participants in the experimental group

- event.c:

  Number of events in the control group

- n.c:

  Total participants in the control group

## Source

Extracted from the `meta` package for demonstration purposes.
