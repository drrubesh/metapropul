# Amlodipine Clinical Trial Dataset

Data from clinical trials comparing Amlodipine to placebo.

## Usage

``` r
data(amlodipine)
```

## Format

A data frame with 8 rows and 7 variables:

- study:

  Study label

- n.amlo:

  Sample size in Amlodipine group

- mean.amlo:

  Mean change in Amlodipine group

- var.amlo:

  Variance in Amlodipine group

- n.plac:

  Sample size in placebo group

- mean.plac:

  Mean change in placebo group

- var.plac:

  Variance in placebo group

## Source

Normand, S.L.T. (1999). Meta-analysis of Amlodipine trials.
