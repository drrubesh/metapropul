# Tabulate publication-bias method availability

Tabulate publication-bias method availability

## Usage

``` r
table_publication_bias(object, output = c("gt", "data"), title = NULL)
```

## Arguments

- object:

  A result returned by
  [`publication_bias()`](https://drrubesh.github.io/metapropul/reference/publication_bias.md).

- output:

  `"gt"` or `"data"`.

- title:

  Optional title.

## Value

A `gt` table or availability tibble.
